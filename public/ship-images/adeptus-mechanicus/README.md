# Adeptus Mechanicus ship images

The Ark illustration comes from [Omnissiah’s Victory](https://ships.battlefleet-game.org/adeptus-mechanicus/omnissiahs-victory-ark-mechanicus.html).
Other classes reuse the Navy or Marine hull illustrations already stored in this
project, matching the hulls linked by the [Mechanicus fleet list](https://battlefleet-game.org/fleet-lists/adeptus-mechanicus/).
These are shared hull illustrations, not newly commissioned Mechanicus liveries.

`manifest.json` records the local asset paths, source pages, original image URLs,
dimensions and access date (October 18, 2026) for all 18 profiles. Images remain
the property of their respective creators and rights holders; see the About page.
