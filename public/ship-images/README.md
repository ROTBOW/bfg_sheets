# Ship images

Keep each faction's images, `manifest.json`, and attribution README together in
a folder named after its lowercase, hyphenated faction slug.

- [Imperial Navy sources](imperial-navy/README.md)
- [Imperial Navy manifest](imperial-navy/manifest.json)
- [Profile schema and adding factions](../ships/README.md)

Manifest filenames are relative to their faction folder. Ship JSONs reference
images with public URLs, for example
`/ship-images/imperial-navy/lunar-class-cruiser.png`.
