# Space Marines

Base profiles and class images from [Battlefleet Gothic Ship Profiles](https://ships.battlefleet-game.org/), checked 2026-10-18. Fleet points and faction rule summaries use the [Remastered Space Marine fleet lists](https://battlefleet-game.org/fleet-lists/space-marines/).

The catalog includes Battle Barge, Strike Cruiser, Seditio Opprimere, Nova, Gladius, Hunter, Fortress-Monastery, and Firestorm / Sword / Cobra / Falchion rapid strike vessels. Rapid strike vessels share the existing Imperial hull images but have separate faction-prefixed class IDs and points. Existing saved Imperial fleets keep their IDs.

This is base-profile support. Optional refits, custom Venerable Battle Barge conversions, Codex / Crusade / Dominion selection and ally eligibility are not automated. The builder displays a manual-review notice for Marine rosters. Fortress-Monastery hull, shields and turrets are per quadrant; track quadrants individually in notes. Its presence does not enable a whole-fortress tracker.

Commander and re-roll costs are supported for the Master of the Fleet. Navy reserve allowances count Navy ships only and do not validate Dominion reserve eligibility.
